# bombive.netlify.app

Página pública de Bombi (inicio + menú). No está conectada a git: se publica arrastrando la carpeta a Netlify
(Deploys → "Drag and drop your project folder"). Cada publicación cuesta 15 créditos.

- `index.html`: inicio con botones (WhatsApp, Ubicación, Menú, TikTok).
- `menu.html`: NY Cookies + "Más delicias" (Banana Bread, Brownie, Thin Cookies), agregado el 2026-10-08.
  Las fotos van incrustadas en el HTML (webp con fondo transparente).
